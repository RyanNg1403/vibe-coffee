## Start the server

```bash
npm install
npm start
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

See the [four café collections](docs/collection/README.md) for current interior
screenshots, distinct countertop displays, revised furniture finishes and

records the varied cast, rebuilt cats and dogs, and movement videos with
verification. The [Blender asset guide](assets/blender/README.md)
contains editable models, source attribution, and regeneration instructions.
Earlier captures remain in [docs/rebuild](docs/rebuild/README.md) and
