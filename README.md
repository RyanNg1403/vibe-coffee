## Start the server

```bash
npm install
npm start
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

See the [architectural realism pass](docs/realism/README.md) for current
interior screenshots, the varied cast, rebuilt cats and dogs, and movement
videos with verification. The [Blender asset guide](assets/blender/README.md)
contains editable models, source attribution, and regeneration instructions.
Earlier captures remain in [docs/rebuild](docs/rebuild/README.md) and
[docs/graphics](docs/graphics/README.md).

See the [NPC movement notes](docs/motion/README.md) for smoothing changes and
the reproducible browser motion audit.
