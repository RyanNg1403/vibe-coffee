# Blender café library

The current runtime library contains **67 original Blender exports**, including
six patrons, a barista, a server, two animated pets, furniture, food, plants,
lighting, venue-specific table assemblies, a piano, a roaster, cars, and street
architecture. The previous imported human cast is excluded from the manifest.
The room shell, interactive counter elements, signs, laptops, and navigation
remain generated by the application around these models.

Editable files are in [rebuild/](rebuild/). Each runtime model has a matching
`.blend` file; `cat.glb` shares `pet_cat.blend`. Materials, deform rigs, and all
five human animation actions remain editable. `cafe-studio.blend` is the earlier
four-prop study, retained as history; it is not the current runtime source.

## Reproduce

From the repository root, with Blender 4.3, Node 24 and FFmpeg installed:

```sh
node tools/export-atelier-layouts.mjs
blender -b -t 4 --python-exit-code 1 --python tools/blender/build_atelier_props.py
blender -b -t 4 --python-exit-code 1 --python tools/blender/build_atelier_people.py
blender -b -t 4 --python-exit-code 1 --python tools/blender/build_atelier_environment.py
blender -b -t 4 --python-exit-code 1 --python tools/blender/build_atelier_pets.py
blender -b -t 4 --python-exit-code 1 --python tools/blender/build_atelier_landmarks.py
node tools/gen-manifest.mjs
node tools/pack-atelier-models.mjs
npm test
npm run build
npm run artifact
```

The generators use the shared helpers in `tools/blender/atelier_common.py`.
Existing project oak and linen maps are packed into the editable sources.
Runtime GLBs embed 256px maps and use Meshopt compression, supported by the
application loader. The current download totals and triangle counts are in
[rebuild/runtime-report.json](rebuild/runtime-report.json). The per-generator
reports record the uncompressed Blender exports.

The standalone HTML includes the entire library. Its export-only optimization
simplifies geometry within a 0.2% relative error budget, removes redundant
animation keys, and preserves the full app's model files. Its limit remains
15.5 MiB.

## Rig and placement conventions

- Metres, Blender Z-up exported as glTF Y-up, human forward along glTF +Z.
- All eight people share a 17-bone deform rig and looping `Idle`, `Walk`,
  `Working`, `Wave`, and `Sitting` actions. Authored skin and clothing colors
  are preserved. Staff use modeled aprons instead of attached box uniforms.
- Walking cadence follows travel speed, rendered poses interpolate simulation
  ticks, turns ease through corners, and sitting blends into the seat pose.
- Tables use the exact application blueprint dimensions and surface heights.
  `atelier_*` environment assemblies keep their metre scale and authored origin.
- Meshopt attributes are decoded to floats before static batching or chair
  instancing. Placed-model bounds are retained for grounding checks, because a
  material batch can contain backrests or shelves without their supporting legs.
- Chairs use two instanced material batches. Model-library resources remain
  shared across venue changes; baked scene geometry is independently owned.
